## 질문 (돌리기 전에 쓴다)

중간 보고(`out_exaone_interim/REPORT.md`)에서 L1 셀 쌍 순위 AUC는 연령만 다른 쌍은 0.76 안팎인데 성별만 다른 쌍은 0.56~0.60으로 우연 근처였다. 이 실험은 성별을 못 잡는 게 (a) 사람 쪽 성별 차이가 원래 작아서인지, (b) 모델이 성별 프롬프트에 아예 반응하지 않아서인지(동점), (c) 반응은 하는데 방향이 틀려서인지, (d) 특정 주제·문항에서만인지를 가른다. 팀 안건(L1 결과를 보고 L2 진행 여부를 정한다)의 근거 자료다.

## 가설과 판정 기준 (돌리기 전에 쓴다)

대상은 서열·이진형 문항(`ordinal_monotone`, `binary`)의 성별만 다른 셀 쌍(같은 연령대의 남-여, 문항당 5쌍)이다. 비교용으로 연령만 다른 쌍을 같이 본다. 쌍 단위 값은 보기 코드 × 확률의 평균 점수 차(여−남)이고, 모델 확률은 보정 없는 원비율이다(`radius_ties.py`와 같은 규칙).
사람 차이는 `human_neff`로 다항 재추출(B=1000)해 95% 구간이 0을 포함하지 않는 쌍을 "유의 쌍"으로 본다.

- **H1 (반응 자체가 약하다):** 유의 쌍에서 모델 점수 차가 정확히 0인 비율(동점률)이 성별에서 연령보다 높고, 평균 |모델 차| / 평균 |사람 차|(크기 비)가 성별에서 연령보다 작다. 둘 다 성립하면 지지.
- **H2 (큰 차이만 잡는다):** 유의 쌍을 |사람 차| 3분위로 나눴을 때 상위 분위의 방향 일치율(AUC, 동점 0.5)이 하위 분위보다 높고, 상위 분위 구간(문항 단위 부트스트랩 95%)의 하한이 0.5를 넘으면 지지.
- **H0 (아무 것도 못 잡는다):** 상위 분위에서도 세 모델 모두 AUC 구간이 0.5를 포함하면, 현재 프롬프트의 성별 정보는 분포를 사람 방향으로 움직이지 못한다는 증거로 읽는다.
- 모델 간 순서나 주제별 차이는 쌍 수가 적어서 탐색 결과로만 적고 판정에는 쓰지 않는다. 층화 셀의 쌍 수가 30 미만이면 AUC를 계산하지 않는다.
- 쓰는 문항 분할: 설정을 고르는 단계가 없는 기술 분석이라 calibration + validation 197문항 전체를 쓰고, validation 49문항만 한 결과도 같이 낸다. test는 쓰지 않는다.
- 한계(미리 적어 둠): EXAONE은 프롬프트당 69~73표본이고 나머지는 100표본이다. 사람 쪽 신뢰구간은 문항·셀별 유효 표본 크기로 근사한 것이라 응답자 재추출 부트스트랩보다 좁을 수 있다.

## 방법

`run.py`가 하는 일. 바꾼 설정은 없다(β·α 적용 안 함, 원비율 사용).

1. `sl.load()`로 L1 행만 가져와 서열·이진형 문항의 셀별 평균 점수(모델, 사람)를 만든다.
2. 성별만 다른 쌍과 연령만 다른 쌍을 만들고, 사람 점수 차의 유의 여부를 다항 재추출로 정한다.
3. 모델×쌍 종류별로 유의 쌍 수, 동점률, 크기 비, 방향 일치율(AUC)과 문항 단위 부트스트랩 구간을 계산한다.
4. 성별 쌍을 |사람 차| 3분위, 주제(`topic`), 민감도(`sensitivity_level`)로 나눠 같은 값을 낸다.
